# Аналитик рынка: ИИ-ассистент консультанта

Прототип продукта для курса «ИИ в бизнес-аналитике». Продукт автоматизирует анализ рынка в консалтинговой компании: ИИ-ассистент готовит черновик отчёта по брифу заказчика, консультант проверяет и правит его, после чего отчёт уходит заказчику на согласование.

**Демо:** https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/ *(замените ссылку после публикации)*

## Соответствие карточке продукта

| Элемент карточки | Где в прототипе |
|---|---|
| Артефакт на входе: структурированный бриф (сведения о заказчике, бизнес-вопрос, границы рынка, требования к анализу и оформлению, данные заказчика) | Этап 01 «Бриф» |
| Ассистент проверяет наличие всех пунктов и сообщает, что уточнить | Этап 02 «Проверка брифа»: статус каждого пункта, письмо заказчику с вопросами, допущения |
| Целевое время работы ассистента: 1 час | Этап 03 «Анализ» и таймер «Время работы ассистента» |
| Артефакт на выходе: черновик отчёта со ссылками на источники | Этап 04 «Валидация» |
| Атрибуты: ссылки на все источники, матрица соответствия требованиям, воспроизводимость расчётов, перечень ограничений | Отчёт и панель «Контроль качества»: формулы пересчитываются автоматически |
| Валидация консультантом | Этап 04: редактирование отчёта, отметки проверенных источников, правки через ассистента, утверждение |
| Потребитель: представитель заказчика, согласование и доработки по комментариям | Этап 05 «Согласование»: отправка, комментарии, новая версия, согласование |
| Знания и источники данных | Раздел «База знаний»: методики, заказчики, отраслевые отчёты, отчёты компаний, статистика |
| Экономический эффект | Раздел «Экономический эффект»: калькулятор |

## Сценарий демонстрации (3–4 минуты)

1. **Бриф** уже заполнен примером. Нажмите «Передать ассистенту на проверку».
2. **Проверка брифа.** Ассистент находит один пункт для уточнения и готовит письмо заказчику. Нажмите «Запустить анализ с допущениями».
3. **Анализ.** Ассистент проходит этапы методики, ожидание можно пропустить.
4. **Валидация.** Контроль качества находит расхождение в расчёте Р7. Нажмите «Редактировать отчёт», исправьте значение Р7 на 70,1 и сохраните новую версию: в ней будет список изменений. Правки можно поручить и ассистенту. Отметьте открытые источники как проверенные и утвердите отчёт.
5. **Согласование.** Отправьте отчёт заказчику, подставьте пример комментариев и передайте их ассистенту. Утвердите версию v3, отправьте её снова и зафиксируйте согласование.

Чтобы начать заново, нажмите «Новый проект» в левой колонке.

## Структура

```
index.html          страница приложения
assets/styles.css   оформление
assets/data.js      пример брифа, база знаний, методики, этапы ассистента
assets/app.js       логика: этапы, проверка брифа, отчёт, контроль качества
```

Сайт статический: нет сервера, сборки и зависимостей. Чтобы запустить его локально, откройте `index.html` в браузере. Прогресс проекта сохраняется в браузере (localStorage).

## Публикация на GitHub Pages

1. Загрузите файлы в корень репозитория, ветка `main`.
2. Откройте Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, папка **/(root)** → Save.
3. Через 1–2 минуты сайт будет доступен по адресу `https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/`.
