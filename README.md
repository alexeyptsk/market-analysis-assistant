# Аналитик рынка: ИИ-ассистент консультанта

Прототип продукта для курса «ИИ в бизнесе». Продукт автоматизирует анализ рынка в консалтинговой компании: ИИ-ассистент готовит черновик отчёта по брифу заказчика, консультант проверяет и правит его, после чего отчёт уходит заказчику на согласование.

**Демо:** [https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/ *(замените ссылку после публикации)*](https://alexeyptsk.github.io/market-analysis-assistant/)

## Соответствие карточке продукта

| Элемент карточки | Где в прототипе |
|---|---|
| Артефакт на входе: структурированный бриф (сведения о заказчике, бизнес-вопрос, границы рынка, требования к анализу и оформлению, данные заказчика) | Этап 01 «Бриф» |
| Ассистент проверяет наличие всех пунктов и сообщает, что уточнить | Этап 02 «Проверка брифа»: статус каждого пункта, письмо заказчику с вопросами, допущения |
| Целевое время работы ассистента: 1 час | Этап 03 «Анализ» и таймер «Время работы ассистента» |
| Артефакт на выходе: черновик отчёта со ссылками на источники | Этап 04 «Валидация» |
| Атрибуты: ссылки на все источники, матрица соответствия требованиям, воспроизводимость расчётов, перечень ограничений | Отчёт и панель «Контроль качества»: формулы пересчитываются автоматически |
| Валидация консультантом | Этап 04: редактирование отчёта, отметки проверенных источников, правки через ассистента, утверждение |
| Потребитель: представитель заказчика, согласование и доработки по комментариям | Этап 05 «Согласование»: отправка, комментарии, новая версия, согласование |
| Знания и источники данных | Раздел «База знаний»: методики, заказчики, отраслевые отчёты, отчёты компаний, статистика |
| Экономический эффект | Раздел «Экономический эффект»: калькулятор |

## Структура

Весь сайт находится в одном файле `index.html`: разметка, оформление и логика.

Сайт статический: нет сервера, сборки и зависимостей. Чтобы запустить его локально, откройте `index.html` в браузере. При каждом открытии сайт запускается в исходном состоянии.
